# Trabajo del Capataz: Guía

La persona quiere saber qué puede hacer con el kit y cómo. Seguí las **reglas de oro** del `SKILL.md`. Respondé **por tareas**, no por nombres técnicos: *"Si querés X, decí Y."*

> Catálogo de la versión **0.3.0** del kit. Se actualiza con cada versión.

## Catálogo

**Del kit, para todos** (paquete `kit-eq`, anda en Cowork y en Code)

| Si querés... | Decí algo como... | Skill |
|---|---|---|
| Empezar de cero, la primera vez | *"Capataz, es mi primera vez"* | `capataz` (Bienvenida) |
| Pensar cómo encarar algo cuando no sabés qué hacer (qué formato, qué datos, qué pestaña) | *"Arquitecto, quiero hacer un informe y no sé cómo"* | `arquitecto` |
| Armar la carpeta de un tema nuevo (en una carpeta vacía alcanza con decir *"inicio"*), o completar la carpeta modelo del curso | *"Capataz, armame una carpeta para la conciliación de proveedores"* | `capataz` (Arrancar) |
| Retomar donde quedaste | *"inicio"* (en una conversación nueva, en la carpeta del tema) | `inicio` |
| Dejar anotado lo que hiciste | *"cierre"* | `cierre` |
| Ver qué podés hacer | *"¿Qué puedo hacer con el kit?"* | `capataz` (Guía) |

## Cómo responder

1. **Mirá qué skills tenés de verdad** en esta conversación y cruzalas con el catálogo:
   - Si una del kit no aparece, decí cómo se consigue: las de `kit-eq` vienen con el paquete (Customize > Plugins); las de `kit-eq-code` se instalan desde Code.
   - Si estás en Cowork, aclará que las de Code no andan acá, sin entrar en detalles.
   - Si la persona tiene skills propias que no son del kit, mencionalas aparte, en una línea.
2. **Si la pregunta es general** (*"¿qué puedo hacer?"*): mostrá la tabla "para todos" y una línea de lo que hay en Code y de lo próximo.
3. **Si la pregunta es concreta** (*"¿cómo hago para...?"*): decí qué skill sirve, la frase para usarla y, si hace falta, en qué carpeta abrir la conversación. Ofrecé arrancarla ya.
4. **Si nada del kit sirve para lo que pide:** decilo y ofrecé hacerlo igual, charlando, en la carpeta del tema.

## Actualizaciones y ayuda

- El kit se actualiza solo si al instalarlo prendieron **"Sync automatically"** (Customize > Plugins > la tienda `kit-eq`). Si no, ahí mismo está **"Check for updates"**.
- Si algo del kit no anda como dice esta guía, que le avisen a quien les dio el curso, con una captura de pantalla.

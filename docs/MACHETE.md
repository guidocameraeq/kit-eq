# Machete del kit eQ

> **Claude se olvida de una conversación a otra. La carpeta, no.**

## Las palabras

| Decí | Cuándo |
|---|---|
| **capataz** | Tenés un tema nuevo: arma la carpeta con unas pocas preguntas |
| **inicio** | Abrís una conversación nueva en la carpeta de un tema: te cuenta dónde quedaron |
| **cierre** | Terminás por hoy: anota qué se hizo y qué sigue, con tu OK |

## Frases que sirven

| Para... | Decí |
|---|---|
| La primera vez | *"Capataz, es mi primera vez"* |
| Un tema nuevo | *"Capataz, tengo un tema nuevo: ..."* |
| Ver todo lo que hay | *"¿Qué puedo hacer con el kit?"* |
| Que planifique antes | *"Antes de hacerlo, contame el plan"* |
| Controlar un resultado | *"Mostrame 3 números y de qué archivo salen"* |
| Anotar una regla para siempre | *"Anotá en el CLAUDE.md que ..."* |
| Ver qué anotó | *"¿Qué dice el SESSION_HANDOFF?"* |
| Seguir los pasos de siempre | *"Corramos la receta"* |

## Los 3 cuidados

1. **Copias, no originales.** Los archivos van copiados a `originales/`. El original queda donde estaba.
2. **Verificá.** Antes de usar un resultado, mirá 3 números contra el archivo original.
3. **Privacidad.** No pegues claves ni datos personales que no hagan falta.

## Para que Claude rinda

- **Un tema por conversación.**
- **Si se pone lento o cambiás de tema:** cierre, conversación nueva e inicio.
- **Dejá la app abierta** mientras trabaja.
- **Datos del sistema:** se sacan en la pestaña Code y se copian a `originales/`.

## La carpeta de cada tema

| Qué | Para qué |
|---|---|
| `CLAUDE.md` | De qué se trata y sus reglas |
| `SESSION_HANDOFF.md` | Dónde quedamos |
| `CHANGELOG.md` | Qué se hizo cada día |
| `RECETA.md` | Los pasos, si el tema se repite |
| `originales/` | Copias de tus archivos |
| `resultados/` | Lo que arma Claude |

¿Algo no anda? Mirá [Si algo no anda](GUIA.md#10-si-algo-no-anda) en la guía de uso, o avisale a quien da el curso con una captura de pantalla.
